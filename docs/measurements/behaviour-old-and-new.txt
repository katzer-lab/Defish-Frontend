# What the page does in six situations, before and after the fixes. 2026-10-04.
# Chrome (headless, via playwright-core) against Vite dev servers: OLD = the client at commit 91b9954, NEW = this working tree;
# the backend is the docker-compose stack of Defish-backend with the MOCK inference service (MOCK_USE_LAYOUT=1, MOCK_DELAY_SECONDS=3).
# Script: docs/capture/behaviour.mjs. Every scenario is one run. "requestsForResults" = GET /analyze-result/... requests the page sent;
# "consoleCharacters" = text the page wrote to the browser console. The photo is the 23 KB synthetic picture.
#
#   normal                         upload, wait for the boxes
#   analysis_failed_on_the_server  the inference service answers 500 (mock switch "broken"): the API reports status "failed"
#   file_over_the_limit_413        an 11 MB file; the API refuses with 413 (limit 10 MB)
#   api_dies_while_polling         the API container is killed 0.8 s after the upload; the page keeps polling
#   cancel_during_analysis         the cancel button 1.5 s into a 3 s analysis; requests are counted after the click
#   api_address_not_configured     a dev server started without VITE_API_URL
# Note 2026-10-06: the OLD run is the original of 2026-10-04; its one Russian message is translated by hand (the old client was Russian).
# The NEW run was repeated on 2026-10-06 (same stack, same scenarios) because the interface texts changed to English; its numbers differ slightly from the run of 2026-10-04.
